# libopensim-tests - SimTK OpenSim Musculoskeletal Simulation C++ library (tests)

This is a `build2` package containing the test suite for the
[`opensim-core`](https://github.com/opensim-org/opensim-core) library. Only
tests for the main OpenSim libraries are included; application and example
tests are not. Tests requiring CasADi are excluded. A small number of upstream
tests are disabled due to known failures on certain platforms or because they
are too slow for routine CI.


## Importable targets

This package exports no targets.


## Configuration variables

This package provides no configuration variables.
